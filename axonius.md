## Senior Technical Support Engineer
**Axonius | Remote | February 2023 – November 2025**

Axonius is an enterprise cybersecurity asset management platform that aggregates device and identity data from across an organization's entire tech stack into a single source of truth. Network devices, cloud instances, SaaS applications, security tools, and identities: it all lands in one place. Security and IT teams use it to find coverage gaps, enforce policies, and answer the question "what do we have and what's running on it?" at enterprise scale.

### What I did day to day

I debugged SaaS integration failures, authentication errors, and data-handling issues across secure cloud environments. That meant pulling logs from Grafana and Coralogix, running curl against REST APIs to isolate payload and auth problems, and reviewing adapter code on GitHub to understand which endpoints an adapter called and which fields it retrieved. I managed roughly 50 active cases at a time while resolving 20 or more tickets weekly.
